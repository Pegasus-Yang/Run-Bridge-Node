# Node 开发回归客户端样例

[开发联调](../调用方联调.md) · [开发环境](../本地开发与联调.md)

这些文件用于 Node 维护者对执行、画面上传和清理合同做联调回归，不是本项目用户部署步骤。Hub 项目保存公开客户端集成指南。

| 文件 | 作用 |
| --- | --- |
| [执行会话调用.py](执行会话调用.py) | 使用夹具或开发许可验证原生 SDK、PNG 与释放 |
| [画面流订阅.py](画面流订阅.py) | 从开发活动会话读取目标和有限帧 |
| [画面查看示例.html](画面查看示例.html) | 对开发协议输出做浏览器展示核验 |

Python 样例不依赖私有服务实现。浏览器测试直接执行开发指南引用的脚本，验证迁移后的示例入口。私有访问文件留在临时夹具／开发配置目录，不进入公开页面目录。
