# Node 调用方联调

[开发导航](本地开发与联调.md) · [联调脚本](examples/README.md)

本文面向维护者，使用已由夹具或开发环境准备好的 Hub、Node、资源和访问许可，验证 Node 的执行、连接清理及画面上传。公开接口的用户集成文档在 Hub 项目维护。

下面在 **Node 源码根目录**操作，使用开发 .venv。访问文件由开发夹具或所有者签发；本指南不启动或部署正式服务。

## 受管理 Chromium 回归

```bash
.venv/bin/python doc/development/examples/执行会话调用.py --access-file .runbridge/dev-access.json --resource-id chromium --screenshot .runbridge/dev-managed.png
```

示例默认 data 页面，验证 SDK 连接、标题、PNG 和 COMPLETE。用实际 fixture 的 URL 和许可运行时，浏览器访问其所在设备可达的地址。

## 已有 Chrome 回归

```bash
.venv/bin/python doc/development/examples/执行会话调用.py --access-file .runbridge/dev-chrome-access.json --resource-id chrome --page-url 'https://your-test-system.example/account' --screenshot .runbridge/dev-chrome.png
```

URL 替换为明确授权实例内唯一匹配的已有页面。读取原页、关闭 SDK 和释放后，核对原浏览器、登录与页面仍保留；页面业务断言另行验证。

## 画面与生命周期

执行脚本增加 --hold-seconds 60 后，使用其实际会话 ID：

```bash
.venv/bin/python doc/development/examples/画面流订阅.py --access-file .runbridge/dev-chrome-access.json --session-id session_example --frame-count 3 --output-dir .runbridge/dev-frames
```

这些开发样例由浏览器回归直接执行，不从用户指南提取任意代码。执行和采集的技术结果不自动判定业务通过。结束时检查 cleanup 及本次进程归属。
