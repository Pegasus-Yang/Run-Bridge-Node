# 当前依赖与实现边界

简体中文 · [English](当前依赖与实现边界.en.md)

适用于 Node 0.8.1；包依赖约束在根 `pyproject.toml`，锁定开发环境在 `uv.lock`。基础工具和浏览器安装方法由对应官网维护。

| 范围 | 当前事实与依据 |
| --- | --- |
| Python / uv | Python 3.14.x、全局 uv 管理本部署 `.venv`；不需要环境内 pip 或另一个部署专用 uv |
| Playwright | `[playwright]` 安装 Python `playwright==1.63.0`；[官方浏览器指南](https://playwright.dev/python/docs/browsers)管理浏览器与系统依赖 |
| managed | Python `chromium.launch()`；库自带 driver，不另部署 Node.js/npm BrowserServer；[官方 launch 合同](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch) |
| borrowed | Python `connect_over_cdp(no_defaults=True)`，仅连接明确授权的本机固定实例；[官方 CDP 合同](https://playwright.dev/python/docs/api/class-browsertype#browser-type-connect-over-cdp)、[Chrome 远程调试说明](https://developer.chrome.com/blog/remote-debugging-port) |
| 画面 | managed 使用同 Page 的 PNG；borrowed 可选 `browscreen>=0.3.1,<0.4.0`，实际验收版本 0.3.1 |
| 系统凭据 | managed 显式保留本地存储启动参数；原理和测试文件见[凭据与测试数据](../deployment/浏览器凭据与测试数据.md) |

Node 只显式实现 33 项项目方法；[Python Playwright 官方 API](https://playwright.dev/python/docs/api/class-playwright)是适配器实现依据，不是本项目完整兼容承诺。对象、异常清理和扩展入口见[代码结构](../architecture/代码结构与执行流程.md)。对外 HTTP/MCP 合同由 Hub 维护，Node 文档不复制另一端的部署和调用步骤。

发布隔离验收见[验收记录](../project/Python工具执行验收记录.md)。原始候选研究见[历史依据](公开依据与研究边界.md)，其中 npm 运行时、SDK 隧道与尚未执行的早期阶段判断不适用于 0.8.1。
