# Current dependencies and implementation scope

[简体中文](当前依赖与实现边界.md) · English

Applies to **Node 0.8.1**. Root `pyproject.toml` defines constraints and `uv.lock` locks development dependencies. Follow vendor documentation for base runtimes and browser installation.

| Area | Current scope |
| --- | --- |
| Python / uv | Python 3.14.x; global uv manages this deployment's `.venv` |
| Playwright | `[playwright]` installs `playwright==1.63.0`; [browser guide](https://playwright.dev/python/docs/browsers) covers browsers/system libraries |
| managed | Python `chromium.launch()` with its bundled driver, without a separate Node.js/npm BrowserServer; [launch API](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch) |
| borrowed | Python `connect_over_cdp(no_defaults=True)` for an explicitly authorized fixed local instance; [CDP API](https://playwright.dev/python/docs/api/class-browsertype#browser-type-connect-over-cdp), [Chrome remote debugging](https://developer.chrome.com/blog/remote-debugging-port) |
| Frames | Managed PNG from the same Page; borrowed optional `browscreen>=0.3.1,<0.4.0`, with recorded live acceptance on 0.3.1 |
| Credentials | Managed explicitly preserves local-storage launch arguments; see [credentials and test data](../deployment/浏览器凭据与测试数据.en.md) |

Node explicitly implements 33 project methods. The [official Python Playwright API](https://playwright.dev/python/docs/api/class-playwright) guides adapter implementation rather than promising full SDK compatibility. Hub maintains the [public method reference](https://github.com/Pegasus-Yang/Run-Bridge-Hub/blob/main/doc/reference/Playwright方法表.en.md) and client HTTP/MCP documentation.

The [code structure (Chinese)](../architecture/代码结构与执行流程.md), [acceptance record (Chinese)](../project/Python工具执行验收记录.md), and [historical research (Chinese)](公开依据与研究边界.md) cover developer/history context. Early npm runtime and SDK-tunnel proposals are not the current deployment model.
