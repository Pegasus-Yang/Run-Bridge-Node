# Node 配置与凭据

简体中文 · [English](部署配置与凭据.en.md)

适用于 0.8.1。首次按[部署手册](../deployment/部署与运行.md)操作；CLI、YAML、浏览器参数的默认值与使用场景统一见[参数详解](参数详解.md)，可复制[带注释 YAML](examples/Node启动配置.yaml)。

`node.yaml` 是部署者编写的启动设置，格式版本为 2；`node.json` 是程序生成的长期身份，格式版本为 1；两者不能互换。配置路径相对 YAML 目录，独立register的 `--config` 路径相对当前工作目录。

## 文件格式与持有人

- enrollment.token：Hub 生成并私密交付，UTF-8 单行文本，32～256 字符，不含引号、Bearer 或 JSON。
- node.json：首次 run 自动生成，含 config_version=1、hub_url、node_id、name、node_token；长期保留于所有者设备，文件 600。
- access.json或YAML：调用方用Hub认证领取后保存access_config，严格含hub_url、node_id、grant_id、access_token、expires_at；新租约必须有带时区到期时间。inspect/session可读取，用后须按Hub手册交还Node。Node不生成此文件，不需要Hub申请令牌。
- `state-node_ID/*.json`：身份目录旁的本次 worker 活动记录，用于确认进程归属与重启恢复。不是用户配置，不手工改写；清理不确定时保留记录排查。

node.json 示例（仅说明结构，秘密由程序生成）：

```json
{"config_version":1,"hub_url":"http://192.168.50.10:8787","node_id":"node_example","name":"office-node","node_token":"EXAMPLE_ONLY_NODE_TOKEN_DO_NOT_USE_00000000000000000000000000000"}
```

不要把 YAML config_version=2 错写到稳定身份 JSON；不要把身份令牌复制成访问令牌。访问 JSON 没有 resource_id，另附资源交付说明。

`prepare-runtime`、`--playwright-config`、`--chrome-config` 已删除。旧运行目录不会自动删除；确认旧服务停止后再由所有者归档。系统钥匙链与本地测试账号文件的区别见[浏览器凭据与测试数据](../deployment/浏览器凭据与测试数据.md)。
