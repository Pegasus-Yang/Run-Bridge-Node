# Node 配置与凭据

适用于 0.6.0。完整[带注释 YAML](examples/Node启动配置.yaml)可复制后修改；部署顺序见[部署手册](../deployment/部署与运行.md)。

## YAML 顶层

| 字段 | 默认值 | 含义与来源 |
| --- | --- | --- |
| config_version | 2 | 当前只支持 2，与身份文件版本不同 |
| hub_url | null | 首次必填，Hub 部署者交付；已有身份可省略，提供时必须与身份一致 |
| name | 机器名 | 首次创建身份的显示名称，不修改已有身份 |
| identity_file | .runbridge/node.json | 稳定身份，首次自动生成，不覆盖 |
| enrollment_token_file | null | Hub 单行文本路径；存在时优先于 RUNBRIDGE_ENROLLMENT_TOKEN |
| tools | {} | 无工具时仅控制连接；当前可配置 playwright |

相对本地路径以 YAML 文件目录为准；不展开 ~ 或 shell 变量。CLI 的 --config/--output 等相对路径则以当前工作目录为准。未知字段、旧顶层 playwright/chrome 和旧 camelCase 启动项会被拒绝。

## tools.playwright

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| resource_id | chromium | 该 Node 资源的 ID，签发许可使用相同值；borrowed 也不自动改名 |
| mode | managed | managed 新建 Chromium；borrowed 连接已有 Chrome |
| browser_cache_directory | null | managed：不设置时保留 Playwright 默认缓存或 PLAYWRIGHT_BROWSERS_PATH |
| launch_options | {} | managed：Python chromium.launch 的允许项，见下表 |
| cdp_endpoint | null | borrowed 必填，本机 ws://127.0.0.1 或 [::1] 的固定 /devtools/browser/ID，无凭据/查询参数 |
| authorization_scope | null | borrowed 必须为 BROWSER_INSTANCE；授权该实例所有页面，不是单页权限 |

borrowed 不接受 browser_cache_directory 或非空 launch_options；managed 不接受 cdp_endpoint/authorization_scope。

### 允许的 launch_options

| 字段 | 默认行为 | 含义 |
| --- | --- | --- |
| headless | true | 无头；false 需要桌面会话 |
| timeout | 本项目 20000 毫秒 | 启动上限 1～30000，不接受 0 |
| channel | 省略 | 选择官方支持的浏览器发行通道 |
| executable_path | 省略 | 自选浏览器文件，相对 YAML 目录；兼容性需自行验证 |
| args | Playwright 默认参数及项目本地存储参数 | 追加自定义启动参数；项目最后保留 --password-store=basic、--use-mock-keychain，避免系统凭据库提示 |
| ignore_default_args | 不忽略 | 按 Python Playwright 规则忽略默认参数；上述两个项目存储参数仍显式传入 |
| chromium_sandbox | Playwright 默认 false | 启用 Chromium sandbox，系统必须支持 |
| slow_mo | 0 | 每步额外延迟毫秒 |
| proxy | 无 | 浏览器上网代理对象，server 必填，bypass/username/password 按官方合同 |
| env | 继承进程环境 | 浏览器环境对象；指定前确认保留必要显示/系统环境 |
| downloads_path / traces_dir / artifacts_dir | 由 Playwright 管理临时位置 | 所有者指定本机输出目录，相对 YAML 目录；不是调用方任意读写接口 |

具体类型遵循 [Python Playwright launch 文档](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch)。本项目只管理以上明确允许的选项，不承诺远程下载、Trace 或任意浏览器特性接口。

系统钥匙链与本地测试账号文件的区别见[浏览器凭据与测试数据](../deployment/浏览器凭据与测试数据.md)。borrowed 的启动参数由原浏览器所有者管理，Node 连接时不能替换。

## 文件格式与持有人

- enrollment.token：Hub 生成并私密交付，UTF-8 单行文本，32～256 字符，不含引号、Bearer 或 JSON。
- node.json：首次 run 自动生成，含 config_version=1、hub_url、node_id、name、node_token；长期保留于所有者设备，文件 600。
- access.json：grant 从 Hub 得到许可后自动写入，含 hub_url、node_id、grant_id、access_token、expires_at；私密交付调用方，过期时间为带时区 ISO 8601 或 null。
- `state-node_ID/*.json`：身份目录旁的本次 worker 活动记录，用于确认进程归属与重启恢复。不是用户配置，不手工改写；清理不确定时保留记录排查。

node.json 示例（仅说明结构，秘密由程序生成）：

```json
{"config_version":1,"hub_url":"http://192.168.50.10:8787","node_id":"node_example","name":"office-node","node_token":"EXAMPLE_ONLY_NODE_TOKEN_DO_NOT_USE_00000000000000000000000000000"}
```

不要把 YAML config_version=2 错写到稳定身份 JSON；不要把身份令牌复制成访问令牌。访问 JSON 没有 resource_id，另附资源交付说明。

## CLI

- `run --settings node.yaml`：登记并上线；已有身份无需重复手工登记。
- `register --hub-url URL --config FILE --enrollment-token-file FILE`：高级维护时独立确认登记，通常不需要。
- `grant --config FILE --resource-id ID --expires-in 秒 --output FILE`：签发；resource-id 可重复，省略覆盖全部；期限省略为无期限。
- `revoke --config FILE grant_ID`：撤销该许可及相关会话。
- `inspect node_ID --access-file FILE --output json`：访问许可查询节点及能力。
- `session create/get/close --access-file FILE`：维护时查询或释放项目会话，不提供官方 SDK 连接。

`prepare-runtime`、`--playwright-config`、`--chrome-config` 已删除。旧运行目录不会自动删除；确认旧服务停止后再由所有者归档。
