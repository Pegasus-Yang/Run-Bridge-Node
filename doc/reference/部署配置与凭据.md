# Node 配置与凭据

[文档导航](../README.md) · [部署与运行](../deployment/部署与运行.md) · [首次接入与许可管理](../user-guide/快速开始.md)

本文对应 Node **0.5.0**，说明本设备的身份、浏览器配置、访问许可与 Node CLI。示例远程 Hub 为 http://192.168.50.10:8787，替换成服务端交付的实际基址；EXAMPLE_ONLY、ID 和时间不是可用凭据。

## 1. 文件清单与通用规则

| 文件／目录 | 如何准备 | 读取入口 |
| --- | --- | --- |
| `enrollment.token` | 从 Hub 部署者取得的同一份纯文本登记文件 | `register --enrollment-token-file` |
| `node.json` | `register --config` 首次生成 | `register/run/grant/revoke --config` |
| `chrome.json` | 所有者确认本机端点后编写 | `run --chrome-config` |
| `playwright.json` | 所有者编写运行时及启动设置 | `run --playwright-config` |
| `playwright/` | `prepare-playwright --runtime-dir` 生成 | JSON 的 `runtime_directory` |
| `access.json` | 所有者 `grant --output` 签发后交付调用方 | `inspect/session --access-file` 及远程调用方 |
| `deploy-constraints.txt`，可选 | 发布者交付的 requirements 依赖约束文本 | `uv pip install --constraint` |

通用规则：

- JSON 使用 UTF-8、双引号和 JSON 的 `true/false/null`，不要添加注释、尾逗号或额外字段。顶层配置拒绝未知字段；`launch_options` 另有明确允许列表。
- 命令行文件路径和 JSON 内的本地相对路径都以**运行命令时的工作目录**为准，不以 JSON 所在目录为准。服务管理器须固定工作目录，或使用绝对路径。
- JSON 不会像 shell 一样展开 `~`、`$HOME` 或 `${变量名}`。例如 `node_executable` 可写 `node` 从 PATH 查找，也可写真实绝对路径。
- 程序不会自动加载 `.env`。环境变量须由当前 shell 或进程管理器传入；不要把 `KEY=value` 写进 token 文件。


## 2. enrollment.token：交付的登记文件

从 Hub 部署者取得同一份 UTF-8 纯文本文件，格式为一行令牌正文。例如：

```text
EXAMPLE_ONLY_ENROLLMENT_TOKEN_DO_NOT_USE_00000000000000000000000
```

不加引号、JSON、Bearer 前缀或 token=，不在 Node 自行生成另一份令牌。生成器通常写入 64 字符随机值，服务端接受长度为 32–256 字符。

Node `register` 优先读取 `--enrollment-token-file`，未提供文件时才读取 `RUNBRIDGE_ENROLLMENT_TOKEN`。文件读取后去掉首尾空白；显式文件不存在或为空时不回退环境变量。

运行、重连及管理许可使用 `node.json` 的长期身份；登记文件不交给普通调用方。

## 3. node.json：长期身份

此文件由 `register` 生成，日常部署无需手写。下面仅用于认识字段：

```json
{
  "config_version": 1,
  "hub_url": "http://192.168.50.10:8787",
  "node_id": "node_11111111111111111111111111111111",
  "name": "office-node",
  "node_token": "EXAMPLE_ONLY_NODE_TOKEN_DO_NOT_USE_0000000000000000000000000000000"
}
```

| 字段 | 必填／默认／格式 | 含义 |
| --- | --- | --- |
| `config_version` | 默认 `1`，当前只接受整数 `1` | 身份文件格式版本，不是 Node 软件版本 |
| `hub_url` | 必填，HTTP(S) 基址 | 此身份所属的 Hub；去掉末尾斜线，不含用户名密码、查询或片段 |
| `node_id` | 必填，标识符 | 登记命令生成的稳定节点 ID |
| `name` | 必填，1–128 字符 | 登记名称；首次由 `--name` 决定，未指定则使用主机名 |
| `node_token` | 必填，32–256 字符 | Node 自身连接 Hub、签发和撤销许可的秘密；不要交给调用方 |

本文的标识符均为 1–128 字符，以字母或数字开头，其余只允许字母、数字、下划线和短横线。适用于 `node_id`、`grant_id`、`resource_id`、`session_id` 等。

`register` 先保存身份，再请求 Hub 登记；因此文件存在不代表登记成功。网络失败后保留文件，用同一命令重试。再次登记时复用其中的 ID、名称和秘密，`--name` 不会覆盖已有名称；不同 Hub 地址拒绝复用同一身份文件。

运行多个不同节点时各用一份独立身份；同一身份的两个常驻连接会互相替换。不要为修复临时断线删除 `node.json`，也不要自行修改 ID 或随机重写 `node_token`。

## 4. 浏览器配置

`run` 一次只能选择 `--chrome-config` 或 `--playwright-config`。两者都不提供时只建立控制连接，没有可执行浏览器资源。

### 4.1 chrome.json：借用已有 Chrome

在 **Node 机器**保存为 `.runbridge/chrome.json`，示例可从 [Chrome 节点配置](examples/Chrome节点配置.json)取得：

```json
{
  "resource_id": "chrome",
  "authorization_scope": "BROWSER_INSTANCE",
  "cdp_endpoint": "ws://127.0.0.1:9222/devtools/browser/aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
}
```

| 字段 | 必填／默认／格式 | 含义 |
| --- | --- | --- |
| `resource_id` | 默认 `chrome`，标识符 | 本 Node 上的资源名；后续 `grant --resource-id` 和会话申请必须使用相同值 |
| `authorization_scope` | 必填，只接受 `"BROWSER_INSTANCE"` | 所有者授权整个浏览器实例可见的页面、上下文与存储 |
| `cdp_endpoint` | 必填，固定浏览器级 WebSocket 地址 | 仅接受 `ws://127.0.0.1:非零端口/devtools/browser/ID` 或 `ws://[::1]:非零端口/devtools/browser/ID`；ID 只含字母、数字、下划线、短横线 |

`localhost`、远程 IP、HTTP 自动发现地址、页面级 `/devtools/page/...`、用户名密码、查询和片段均不能放入此字段。通过所有者已授权端口的 `/json/version` 取得 `webSocketDebuggerUrl` 后保存实际值；具体生成命令见[Chrome 快速开始](../user-guide/Chrome复用快速开始.md)。示例中的 ID 必须替换。

Node 不启动或关闭该 Chrome，也不自动换绑同端口的新浏览器。Chrome 重启导致浏览器 ID 变化后，由所有者重新确认端点并更新配置，再正常重启 Node。

### 4.2 playwright.json：每个会话新建 Chromium

在 **Node 机器**保存为 `.runbridge/playwright.json`，也可使用 [Playwright 节点配置](examples/Playwright节点配置.json)：

```json
{
  "runtime_directory": ".runbridge/playwright",
  "node_executable": "node",
  "resource_id": "chromium",
  "launch_options": {
    "headless": true
  }
}
```

| 字段 | 必填／默认／格式 | 含义 |
| --- | --- | --- |
| `runtime_directory` | 必填，目录路径 | `prepare-playwright --runtime-dir` 准备的目录，含 `node_modules/playwright` 和 `browsers/`；加载时转换为绝对路径 |
| `node_executable` | 默认 `"node"` | 启动私有 npm Playwright 服务的 Node.js 命令或绝对路径；不是 Python 的 `runbridge-node` |
| `resource_id` | 默认 `"chromium"`，标识符 | 此受管理资源的名称，须与签发许可及会话申请保持一致 |
| `launch_options` | 默认 `{}`，JSON 对象 | 所有者传给 Node.js `chromium.launchServer()` 的启动选项；使用下面的 camelCase 字段 |

安装 npm 运行时需 Node.js >=20，且 npm 在 PATH 中。`prepare-playwright --node-executable` 只指定该次准备使用的 Node.js；服务运行时仍按 JSON 的 `node_executable` 查找。使用绝对路径时，两处应选同一套 Node.js。运行时将 `PLAYWRIGHT_BROWSERS_PATH` 设为此目录下的 `browsers/`，不能通过普通外部同名环境变量替换它。

### 4.3 launch_options 的完整允许列表

所有字段均可省略。除 RunBridge 明确指定的默认值外，由随包锁定的 Playwright **1.63.0** 处理；Node 先检查字段名，具体类型和值由 Playwright 校验。使用其他字段会被拒绝。

| 字段 | JSON 类型／默认行为 | 含义与单位 |
| --- | --- | --- |
| `args` | 字符串数组，默认无额外参数 | 额外 Chromium 启动参数；不要把整条 shell 命令写成一个字符串 |
| `artifactsDir` | 目录字符串，默认临时目录 | 浏览器产物根目录；显式指定时目录不由浏览器退出自动删除，具体文件保留还受其生命周期约束 |
| `channel` | 字符串，默认随运行时准备的 Chromium | 选择已安装的浏览器通道，如 `chrome` 或 `chromium`；不会自动准备所选通道 |
| `chromiumSandbox` | 布尔值，Playwright 默认 `false` | 是否启用 Chromium 沙箱，需目标系统支持 |
| `downloadsPath` | 目录字符串，默认临时目录 | Node 侧接收下载的位置；下载仍可能在对应 Context 关闭时删除，调用方持久保存使用 SDK 的 `save_as()` |
| `env` | 字符串到字符串的对象，默认继承运行时环境 | 给浏览器进程指定环境，例如 `{"LANG":"zh_CN.UTF-8"}`；显式对象作为浏览器环境传入，不应假定自动合并全部原环境 |
| `executablePath` | 路径字符串，默认运行时缓存中的浏览器 | 指定另一份实际浏览器文件；相对启动目录解析，兼容性需在目标环境验证 |
| `headless` | 布尔值，默认 `true` | `true` 无窗口，`false` 显示窗口；Linux 显示窗口需要可用图形会话 |
| `ignoreDefaultArgs` | 布尔值或字符串数组，默认 `false` | `true` 取消全部默认浏览器参数；数组仅去掉列出的默认参数，可能影响协议能力 |
| `proxy` | 对象，默认不显式设置 | 浏览器访问业务网页使用的代理；与 Node 连接 Hub 的代理不同，子字段见下表 |
| `slowMo` | 数字，毫秒，默认无额外延迟 | 延缓浏览器动作，便于观察；不能用作页面就绪判断或业务超时 |
| `timeout` | 数字，毫秒，RunBridge 默认 `20000` | 浏览器启动超时；`0` 仅关闭此层超时，不能取消 Node 外层等待 |
| `tracesDir` | 目录字符串，默认未指定 | 浏览器侧 trace 文件目录；设置目录本身不会开始 tracing |

`proxy` 提供时，格式为对象：

| 子字段 | 是否必填 | 含义 |
| --- | --- | --- |
| `server` | 必填，字符串 | HTTP／SOCKS 代理地址，例如 `http://127.0.0.1:3128` 或 `socks5://127.0.0.1:1080`，地址指 Node 网络 |
| `bypass` | 可选，字符串 | 逗号分隔的绕过域名，如 `localhost,.example.test` |
| `username` | 可选，字符串 | HTTP 代理认证用户名 |
| `password` | 可选，字符串 | HTTP 代理认证密码，配置文件按私有文件保管 |

这些本机目录属于 Node，不能当作调用方的下载／截图路径。Node 外层等待 helper 就绪最多 **30 秒**，其中还包括浏览器探测；调大 `timeout` 不能延长这一限制。监听地址固定为 `127.0.0.1`、端口自动分配、关闭信号由 Node 管理，因此 `host`、`port`、`wsPath` 和信号处理字段不能配置。没有 `userDataDir` 字段，不通过此模式复用日常 Profile。

选项语义可对照 [Playwright launchServer 官方说明](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-server)，RunBridge 接受的范围以本表和当前 `LAUNCH_KEYS` 为准。

## 5. access.json：交付调用方的许可

由 Node 所有者通过 `grant --output` 生成，文件名也可以是 `chrome-access.json`、`playwright-access.json` 或 `agent-access.json`，内容格式相同：

```json
{
  "hub_url": "http://192.168.50.10:8787",
  "node_id": "node_11111111111111111111111111111111",
  "grant_id": "grant_22222222222222222222222222222222",
  "access_token": "EXAMPLE_ONLY_ACCESS_TOKEN_DO_NOT_USE_00000000000000000000000000000",
  "expires_at": "2030-01-01T01:00:00Z"
}
```

| 字段 | 必填／格式 | 含义 |
| --- | --- | --- |
| `hub_url` | 必填，HTTP(S) 基址 | 调用方连接的 Hub，须从调用方网络可达；不能填写 Node 的浏览器调试地址 |
| `node_id` | 必填，标识符 | 许可所属节点，不得替换为另一节点 |
| `grant_id` | 必填，标识符 | 所有者撤销许可时使用的 ID |
| `access_token` | 必填，字符串 | Hub 签发的调用凭据原值；JSON 中不加 `Bearer `，请求时使用 `Authorization: Bearer <access_token>` |
| `expires_at` | 可省略或 `null`；否则为带时区的 ISO 8601 时间 | Hub 返回的到期时间，如 `Z` 或 `+08:00`；`null` 表示签发时未设置期限，不是永久不可撤销 |

时间和令牌均由签发命令填入，示例时间不是实际期限。资源范围由 `grant --resource-id` 写入 Hub 的许可记录，文件中没有 `resource_ids` 字段；不要自行添加。更改本地 `expires_at`、ID 或令牌不能修改 Hub 授权，续期须重新签发。

MCP 客户端读取同一访问令牌，以每次请求头认证，MCP 地址为 Hub 基址加 `/mcp`。`node_token` 和 `enrollment.token` 都不能替代它。调用方只接收访问文件，Node 身份、登记文件及本机浏览器配置由所有者保留。

## 6. Node 命令参数

以下为 `runbridge-node` 后面的子命令。在 Node 部署目录使用 `.venv/bin/runbridge-node ...`，或 `uv run --no-project --python .venv/bin/python runbridge-node ...`。`-h/--help` 查看本机版本帮助。

### 6.1 register：首次登记或同一身份重试

| 参数 | 默认／要求 | 含义 |
| --- | --- | --- |
| `--hub-url` | 必填 | Node 可达的 Hub HTTP(S) 基址；已有身份时必须匹配文件中的基址 |
| `--enrollment-token-file` | 未设置 | 读取第 2 节纯文本文件；省略时用 `RUNBRIDGE_ENROLLMENT_TOKEN` |
| `--name` | 当前主机名 | 新身份的显示名称，1–128 字符；已有身份继续使用文件内名称 |
| `--config` | `.runbridge/node.json` | 身份保存路径；首次自动生成，重试加载原文件 |

### 6.2 run 与 prepare-playwright：启用资源

| 命令 | 参数 | 默认／要求 | 含义 |
| --- | --- | --- | --- |
| `run` | `--config` | `.runbridge/node.json` | 已登记身份文件 |
| `run` | `--chrome-config` | 未设置 | 已有 Chrome 配置；与下一项互斥 |
| `run` | `--playwright-config` | 未设置 | 受管理 Chromium 配置；不提供两种配置时仅保持控制连接 |
| `prepare-playwright` | `--runtime-dir` | `.runbridge/playwright` | 安装私有 npm 依赖和 Chromium 的目录，须与 JSON 中 `runtime_directory` 对应 |
| `prepare-playwright` | `--node-executable` | `node` | 准备时使用的 Node.js；npm 仍须在 PATH 中，不会修改 `playwright.json` |

运行时安装使用包内 `package.json/package-lock.json`，不要手改生成文件。目录内已有不同依赖文件时命令拒绝覆盖，升级时选择新运行时目录并更新本地配置；不通过删除共享缓存修复。

### 6.3 grant 与 revoke：签发和撤销调用许可

| 命令 | 参数 | 默认／要求 | 含义 |
| --- | --- | --- | --- |
| `grant` | `--config` | `.runbridge/node.json` | 使用该节点身份签发 |
| `grant` | `--output` | 必填，文件路径 | 生成第 5 节的访问 JSON；已有文件时不签发新许可、不覆盖 |
| `grant` | `--resource-id` | 未限制，可重复 | 限制允许的资源 ID，须与浏览器配置相同；省略表示此节点可见资源不限 |
| `grant` | `--expires-in` | 未设置期限 | 有效秒数，可带小数，必须大于 0 且不超过 31536000；建议显式设定，如 `3600` |
| `revoke` | `grant_id` | 必填，位置参数 | 撤销的许可 ID，来自访问文件或签发输出 |
| `revoke` | `--config` | `.runbridge/node.json` | 使用许可所属节点身份撤销 |

一个节点可为不同调用方分别签发许可。撤销会使后续认证失败，并触发该许可的活动会话关闭；不注销节点，也不回滚已有业务动作。

### 6.4 inspect：调用方查询

| 参数 | 默认／要求 | 含义 |
| --- | --- | --- |
| `node_id` | 必填，位置参数 | 要查询的节点 ID |
| `--access-file` | 未设置，推荐提供 | 第 5 节的访问文件，读取其中的 Hub 基址和访问令牌 |
| `--hub-url` | 未设置 | 显式提供时覆盖访问文件里的基址，仍须指向同一个 Hub |
| `--output` | `json`，当前只允许 `json` | 输出格式，JSON 写到标准输出；此参数不是文件路径 |

不提供 `--access-file` 时，须同时提供 `--hub-url` 和环境变量 `RUNBRIDGE_ACCESS_TOKEN`。提供访问文件后使用文件里的令牌，不再读取该环境变量。

### 6.5 session：调用方管理会话

| 子命令 | 参数 | 默认／要求 | 含义 |
| --- | --- | --- | --- |
| `create/get/close` | `--access-file` | 必填 | 创建该会话的调用许可文件；同节点另一份许可不能接管 |
| `create` | `--resource-id` | `chromium` | 要申请的资源；Chrome 模式通常须改为 `chrome` 或实际配置的 ID |
| `create` | `--client-version` | 必填，`数字.数字.数字` | 调用方 Playwright SDK 版本，如 `1.63.0`；不是 RunBridge 版本或 Chrome 产品版本 |
| `create` | `--lease-seconds` | `300`，秒，可带小数 | 1–3600 秒；最终到期不超过许可到期时间 |
| `get/close` | `session_id` | 必填，位置参数 | 创建响应中得到的会话 ID |

`create` 创建会话，`get` 查询状态，`close` 请求释放；会话 ID 和技术状态不能替代业务执行结果。Node 操作见[许可管理](../user-guide/快速开始.md)；SDK／HTTP 调用方接入由 Hub 项目文档维护。

## 7. 权限、环境变量与格式排查

首次在各自部署目录准备配置目录：

```bash
umask 077
mkdir -p .runbridge
chmod 700 .runbridge
```

生成的 token、身份和访问文件使用 POSIX `0600`，新建父目录使用 `0700`；现有目录不会自动收紧权限。手工编写或复制的 token、浏览器 JSON 也应设置 `chmod 600 文件路径`，不要放入静态网页目录或 Git。

| 变量 | 读取者 | 含义 |
| --- | --- | --- |
| `RUNBRIDGE_ENROLLMENT_TOKEN` | Node `register` | 未提供登记文件时的令牌正文，不含 `Bearer `；文件参数优先 |
| `RUNBRIDGE_ACCESS_TOKEN` | Node `inspect` | 未提供访问文件时的查询凭据；须配合 `--hub-url`，不替代 `session --access-file` |
| `PATH` | shell、Node 运行时准备与启动 | 必须能找到全局 uv，以及受管理模式需要的 Node.js/npm；SSH 非交互环境可能与交互终端不同 |
| `UV_CACHE_DIR` | uv | 可选安装缓存目录，不决定使用哪一套 `.venv`；通过 `uv pip list --python .venv/bin/python` 等命令显式选环境 |
| `HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY` | 网络库／工具 | 影响 Hub 连接或下载；不是浏览器 JSON 的 `proxy` 字段，详见[部署与运行](../deployment/部署与运行.md) |

常见排查：

| 现象 | 先核对 |
| --- | --- |
| 登记认证失败 | 两端是否使用同一个纯文本 token，是否误加引号／JSON／`Bearer ` |
| 配置无效、退出码 2 | JSON 是否完整、是否有额外字段、凭据长度和固定枚举是否正确 |
| 找不到配置或运行时 | 当前工作目录、相对路径及 JSON 中未展开的 shell 变量 |
| 已有身份文件但 Node 未登记 | 首次网络请求是否成功；保留身份并用原命令重试 |
| 访问文件修改期限后仍返回 401 | 期限以 Hub 记录为准；由所有者重新签发 |
| Node ONLINE 但没有浏览器资源 | 是否提供了一种浏览器配置，目标资源是否真正 `READY/FREE` |
