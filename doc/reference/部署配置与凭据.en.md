# Node configuration and credentials

[简体中文](部署配置与凭据.md) · English

Applies to **Node 0.8.1**. Start with [deployment](../deployment/部署与运行.en.md); see [parameters](参数详解.en.md) and [annotated YAML](examples/Node启动配置.en.yaml) for options.

The deployer writes `node.yaml` (startup format 2). Node generates `node.json` (stable identity format 1). These are different files. YAML paths resolve from its directory; standalone `register --config` paths resolve from the working directory.

## Files and owners

- **`enrollment.token`**: generated by Hub and privately delivered; UTF-8 single-line text, 32–256 characters, without quotes, Bearer, or JSON.
- **`node.json`**: generated by first `run`, with `config_version=1`, `hub_url`, `node_id`, `name`, `node_token`; retained on the owner device, mode 600.
- **Access JSON/YAML**: client saves Hub's returned `access_config`, exactly `hub_url`, `node_id`, `grant_id`, `access_token`, `expires_at`. Current leases require timezone-aware expiry. Diagnostics can read it; the client releases Node afterward. Node does not generate this file or need a Hub claim token.
- **`state-node_ID/*.json`**: worker activity records beside identity, used for process ownership and restart recovery. They are not user configuration. Preserve them when cleanup is uncertain.

Identity illustration; the actual secret is generated by Node:

```json
{"config_version":1,"hub_url":"http://192.168.50.10:8787","node_id":"node_example","name":"office-node","node_token":"EXAMPLE_ONLY_NODE_TOKEN_DO_NOT_USE_00000000000000000000000000000"}
```

Do not put YAML format 2 into stable identity JSON or reuse the identity token for access. Access configuration has no `resource_id`; hand off that identifier separately.

Old `prepare-runtime`, `--playwright-config`, and `--chrome-config` are removed. Existing directories are not deleted automatically; archive after verifying the old service stopped. See [browser credentials and test data](../deployment/浏览器凭据与测试数据.en.md) for the distinction from system keychains and local test-account files.
