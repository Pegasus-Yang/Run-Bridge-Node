# RunBridge Node 项目概况

[项目首页](../../README.md) · [文档导航](../README.md) · [部署与运行](../deployment/部署与运行.md)

当前 Node 0.5.0 部署在浏览器所有者设备，主动连接已经存在的远程 Hub。本项目用户文档面向设备所有者，维护节点身份、授权浏览器资源和调用许可。

## 当前职责

Node 完成本机能力探测、稳定身份连接、受管理 Chromium 生命周期、已有 Chrome 的实例借用、执行出站隧道，以及可选 Browscreen PNG 上传。

所有者选择一种浏览器模式并检查 READY/FREE，给调用方交付独立访问 JSON。调用方的公开 HTTP／MCP／SDK 集成由 Hub 项目文档维护；本机端点、登记文件和 Node 身份留在设备。

## 阅读路线

按部署指南安装发布包并保存统一 YAML，再选[Chrome 复用](../user-guide/Chrome复用快速开始.md)或[受管理 Chromium](../user-guide/Playwright快速开始.md)，一次启动完成登记和上线。日常[许可管理](../user-guide/快速开始.md)、[画面采集](../user-guide/浏览器画面采集.md)和排障均在本项目说明。

源码安装、构建、同机联调和回归属于[开发与联调](../development/本地开发与联调.md)。Node 内部协议维护资料集中在开发区，历史验收只代表当次版本与环境。

独立业务 HTTP 执行、Appium／ADB、单标签页授权和容量目标仍是后续范围。
