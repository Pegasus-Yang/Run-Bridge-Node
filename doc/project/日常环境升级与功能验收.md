# 0.6.0 日常环境升级与功能验收

核验日期：2026-10-19（Asia/Shanghai）。本次将原有 Ubuntu ARM64 的 managed/borrowed 两套 Node 升级到 0.6.0，使用同一全局 uv 管理各自 `.venv`，启动统一改为 YAML 版本 2。

升级前备份身份、配置和专用 Chrome Profile；原 Node ID、身份 JSON 哈希不变。Python Playwright 1.63.0 安装在 Node 同一环境，borrowed 画面使用 Browscreen 0.3.1。最终 wheel 的全部 Python 文件与源码及两套实际安装内容一致，不再运行 npm BrowserServer。

## 功能与恢复

macOS 完整 Node 测试 71 项通过；虚拟机实际安装环境的 4 项真实 worker 用例通过，覆盖正常关闭、worker/driver 异常、后台原页面输入点击及释放后原 Chrome/两页/Cookie/localStorage 保留。

配套日常 Hub 上的 18 项集成用例通过，实际执行全部 33 项项目方法、27 个 MCP 工具。验证最终表单记录、上传内容、截图/持续画面、页面选择、弹窗与 iframe、并行隔离、租期/撤销、去重不重做。Node 强制退出后在途结果 UNKNOWN，同身份重启清理所属进程并恢复 READY/FREE；原有身份和许可继续有效。

HTTP/MCP/Python 画面示例执行成功；实际 Chrome 中的 HTML 查看器完成首消息认证、1280×720 画布绘制和会话结束后撤图。验收结束时两套日常 Node 保持在线，资源 READY/FREE，无活动工具 worker。

## 本轮修正与文档

managed 强制保留不访问系统凭据库的 Chromium 启动参数，直接启动的测试 Chrome 同步补齐，测试数据保存在私有文件。独立 Profile 实测确认所有者脚本能从文件读取合成 Cookie 和账号标记，不使用系统钥匙链；详见[凭据与测试数据](../deployment/浏览器凭据与测试数据.md)。

borrowed 鼠标、键盘及表单输入在操作前激活调用方明确指定的 Page，修复后台页动画帧暂停造成的点击等待；只读操作不切换前台。用户手册、YAML 注释、故障处理、代码结构和依赖边界均已同步；基础工具安装继续由官网负责。

私人机器记录和凭据仅存于忽略的本地材料，不放入本项目公开文档。此前[发布隔离验收](Python工具执行验收记录.md)保留其阶段语境；旧 npm/SDK 资料保留历史标记，不能用于当前部署。
