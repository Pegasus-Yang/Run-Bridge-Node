# Node 版本发布记录

## 0.8.0（2026-10-23）

- 配套Hub0.9.0，将整个Node使用权统一交给Hub分配；移除grant/revoke命令及设备客户端发证、撤销方法，node_token继续用于设备连接。
- 保留注册、能力探测、执行与清理；inspect/session仅作为已有Hub租约的可选诊断。五字段访问文件新增YAML读取，原JSON继续可读。
- 同步首页、快速开始、部署、参数、MCP准备、架构和升级文档，不新增用户概念或Node侧Hub申请凭据。Node YAML格式2、身份格式1、执行协议2保持。旧访问许可按Hub升级规则重新领取。

完整pytest 75 passed，含4项真实worker/浏览器检查；新Hub/Node wheel独立安装后11项真实MCP/Chromium联调通过，见[迁移验收](Node使用权迁移验收.md)。本地附注tag v0.8.0；包为dist/runbridge_node-0.8.0-py3-none-any.whl及dist/runbridge_node-0.8.0.tar.gz。不推送、不升级已有运行环境。

## 0.7.0（2026-10-19）

重写首页、快速开始与参数详解，简化默认参数，补齐配置注释、浏览器会话验证与常见问题。Node 执行行为不变。

本次发布版本为 **0.7.0**，与另一端 0.7.0 配套；当前分支为 `main`，本地附注 tag 为 `v0.7.0`。提交与 tag 均不推送。

执行协议仍为 2、playwright 工具 API 仍为 1、画面协议仍为 1；数据库 schema 4、Hub YAML 格式 1、Node YAML 格式 2、身份 JSON 格式 1 均未改变。无需因版本号变化重新生成身份或许可。

当前操作见[快速开始](../user-guide/快速开始.md)、[参数详解](../reference/参数详解.md)与[升级说明](../deployment/运行与排障.md)。代码版本、安装元数据、锁文件和当前文档同步更新；旧设计、验收与原始证据保留原版本和日期。

本轮按用户要求不启动服务：只执行配置解析、路径和文件保持检查、静态/单元验证及打包校验。此前 0.6.0 的真实浏览器和日常环境验收保留原证据，不能写成 0.7.0 已在日常环境启动验证。实际运行留给操作者按手册完成。

安装版本可在目标环境执行：

```bash
.venv/bin/python -c 'from importlib.metadata import version; print(version("runbridge-node"))'
```

本机和虚拟机的私有配置、数据及待人工验证的部署状态不进入 Git；打 tag 不会自动安装或升级远程环境。

## 本地安装包交付约定

每次版本更新都在本仓库 `dist/` 生成对应 wheel 与源码分发包，不能只保留私有目录中的构建。0.7.0 的标准包已补齐，文件名分别为 `runbridge_node-0.7.0-py3-none-any.whl`、`runbridge_node-0.7.0.tar.gz`；使用对应版本文件在自己的 `.venv` 安装。完整步骤见[版本发布与本地打包](../development/版本发布与本地打包.md)。本次补包不移动已存在的 `v0.7.0` tag。
