# Node 为已有 Chrome 启用持续画面

[文档导航](../README.md) · [Node 部署](../deployment/部署与运行.md) · [Chrome 复用](Chrome复用快速开始.md) · [配置参数](../reference/部署配置与凭据.md)

本文带 Node 所有者为已授权的 Chrome 开启 PNG 采集。调用方如何订阅和展示由 Hub 项目的《浏览器画面流接入》说明；你在本设备准备采集能力和访问许可。

## 1. 先确认你使用的路线

| 浏览器模式 | 是否执行下面的安装步骤 |
| --- | --- |
| 已有 Chrome，需要持续画面 | 执行；浏览器实例与 `chrome.json` 应已经准备好 |
| 受管理 MCP 浏览器 | 不执行；按受管理指南准备运行时，画面由 Hub 同页采集 |
| 普通 SDK 受管理会话 | 不执行；当前没有独立画面流，装上扩展也不会改变它 |

如果还没完成 Node 登记和 Chrome 配置，先按部署指南走完，再返回这里。只有本机浏览器就绪，才能核对采集能力。

## 2. 安装扩展并正常重启 Node

先让调用方释放活动会话，在原 Node 服务终端按 Ctrl+C 停止 Node。**保留原 Chrome 及其 Profile**。

另一个终端进入原部署目录，使用当初收到的同版 wheel：

```bash
cd ~/runbridge-node
uv pip install --python .venv/bin/python './runbridge_node-0.5.0-py3-none-any.whl[visual]' -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
uv pip check --python .venv/bin/python
```

`[visual]` 安装 Browscreen 正式版 `>=0.3.1,<0.4.0`。若 wheel 不在部署目录，从本次发布材料中重新复制，不能新建一个同名空文件。发布者有约束文件时继续使用对应 `--constraint`。

重新启动一份 Node，保持终端运行：

```bash
.venv/bin/runbridge-node run --config .runbridge/node.json --chrome-config .runbridge/chrome.json
```

## 3. 用有效访问文件检查能力

打开新的 Node 终端。以下沿用部署指南生成的 `access.json`，文件名不同时改成实际文件：

```bash
cd ~/runbridge-node
rb_node_id=$(.venv/bin/python -c 'import json; from pathlib import Path; print(json.loads(Path(".runbridge/node.json").read_text())["node_id"])')
.venv/bin/runbridge-node inspect "$rb_node_id" --access-file .runbridge/access.json
```

应看到所需 Chrome 资源就绪，并有 `visual.supported=true`。还没有该许可的活动会话时，`visual.streams=[]` 正常：声明“能采集”与已经产生画面是两回事。

如果扩展导入失败、版本不符或未安装，基础执行仍可保留，但画面是否可用以真实上报为准，不能只看安装命令退出成功。

## 4. 让调用方完成实际订阅

将原访问文件、资源 ID 和已有页面信息交给调用方，说明已启用采集，让其按 **Hub 项目《浏览器画面流接入》**操作：

1. 使用这份许可建立并保持原生浏览器会话，使其进入 ACTIVE。
2. 用同一许可订阅该会话，必要时明确选择画面目标。
3. 检查 LIVE、新鲜帧和实际 PNG 内容，然后正常释放会话。

这里只说明双方配合顺序，调用方命令不在 Node 部署步骤中执行。不同许可不能查看对方会话；选择画面目标也不会把整个浏览器授权缩小为单页。

## 5. 结束和排查

会话结束后采集和上传停止；订阅者单独退出只停止查看，不结束业务执行。Node 只回收自己创建的采集进程和临时目录，原 Chrome 继续由所有者管理。

中文方框先按[部署指南字体章节](../deployment/部署与运行.md#9-ubuntu-中文字体按需)在浏览器所属用户下安装字体、刷新缓存，再由所有者重启浏览器并更新授权端点。STALE／ERROR 或 cleanup=UNKNOWN 按[Node 排障](../deployment/运行与排障.md)核查，不能把旧图当作实时结果。
