# Node 浏览器画面采集

简体中文 · [English](浏览器画面采集.en.md)

0.8.1 的 managed 使用当前 Python worker 的同一 Page 采集，不需要 `[visual]`；动作 page_id 与画面 target_id 一致。正常 run 会探测截图能力，调用方按 Hub 查询返回的 visual 路径订阅，无需所有者收集流地址。

borrowed 模式保留可选 Browscreen 扩展。需要时在停止本实例后，将同一 wheel 安装为 `[playwright,visual]`，命令写法与[部署安装](../deployment/部署与运行.md)相同，只替换 extra。版本范围 browscreen>=0.3.1,<0.4.0，实际启动探测通过后才声明支持。重启仍使用同一 YAML；不增加单独的浏览器服务启动命令。

该扩展独立采集，不占用动作队列。多页需调用方明确选择，已关闭页不会自动切到别的登录页面。原始 CDP target 映射为会话 Page 引用，内部端点留在本机。授权仍覆盖整个实例。

图片只供观察。字体、图形会话、窗口状态和系统依赖由设备管理员管理；不能将 LIVE 或截图成功当作业务提交成功。会话关闭后应撤下旧图，清理不确定时资源隔离。调用方操作规范由 Hub 的画面手册维护。
