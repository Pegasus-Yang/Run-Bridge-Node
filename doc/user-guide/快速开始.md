# Node 首次接入与许可管理

[文档导航](../README.md) · [部署 Node](../deployment/部署与运行.md) · [Node 配置与凭据](../reference/部署配置与凭据.md)

适用于 Node 0.5.0。先在本设备完成发布包安装，并从远程 Hub 部署者取得实际基址和登记纯文本文件。以下命令都在 Node 部署目录运行，示例远端地址为 `http://192.168.50.10:8787`。

## 1. 登记本设备

把收到的文件放为 `.runbridge/enrollment.token`，按部署指南限制文件权限后执行：

```bash
.venv/bin/runbridge-node register --hub-url http://192.168.50.10:8787 --enrollment-token-file .runbridge/enrollment.token --config .runbridge/node.json --name office-node
```

保存实际 `node_id`。命令先保存身份，再请求远端登记；失败保留原文件重试。同一身份重试响应 `created=false` 属于正常结果，不能删除身份来修复临时网络问题。

## 2. 准备并启动资源

选择[Chrome 复用](Chrome复用快速开始.md)或[受管理 Chromium](Playwright快速开始.md)，准备对应 JSON 后前台运行一种模式：

```bash
.venv/bin/runbridge-node run --config .runbridge/node.json --chrome-config .runbridge/chrome.json
```

受管理模式将浏览器参数换为 `--playwright-config .runbridge/playwright.json`。两者互斥，一个身份只运行一个常驻进程。仅做控制连接诊断时可省略浏览器参数，此时没有浏览器资源。

## 3. 签发许可并检查状态

在另一个终端执行；资源 ID 应与自己的配置相同：

```bash
.venv/bin/runbridge-node grant --config .runbridge/node.json --resource-id chrome --expires-in 3600 --output .runbridge/chrome-access.json
.venv/bin/runbridge-node inspect node_example --access-file .runbridge/chrome-access.json --output json
```

`node_example` 替换为自己的节点 ID。预期 `connection_status=ONLINE`、`capabilities_stale=false`，目标资源 `readiness=READY`、`occupancy=FREE`。仅 ONLINE 不说明浏览器可用。

未限制资源的许可可以在受控诊断时用于纯控制查询，但日常交付建议显式指定资源和期限。已有输出文件时复用有效许可或使用新文件名；命令不覆盖已有文件。

## 4. 交付给调用方

交付访问 JSON 和实际资源 ID，并说明浏览器模式。访问文件包含 `hub_url/node_id/grant_id/access_token/expires_at`；Node 身份、登记文件和浏览器本机端点由所有者保留。

HTTP、MCP、SDK 操作和画面订阅由调用方按 **Hub 项目**的接口文档接入。业务网页应从 Node 浏览器网络可达，许可文件中的 Hub 地址则须从调用方网络可达。

## 5. 撤销、结束与续期

用访问文件中的真实 `grant_id` 撤销：

```bash
.venv/bin/runbridge-node revoke grant_example --config .runbridge/node.json
```

撤销或到期会使旧许可失效，并触发其活动会话关闭。续期应重新签发新文件，不能修改旧 JSON 的到期时间；新许可不能接管旧许可的会话。

按[运行与排障](../deployment/运行与排障.md)确认清理。正常停止 Node 使用 Ctrl+C／SIGTERM；已有 Chrome 保留，受管理实例随清理回收。

## 6. CLI 会话诊断

所有者持有某份访问许可时，可查询或请求关闭**该许可创建**的会话：

```bash
.venv/bin/runbridge-node session get session_example --access-file .runbridge/chrome-access.json
.venv/bin/runbridge-node session close session_example --access-file .runbridge/chrome-access.json
```

会话 ID 替换为实际值。完整 CLI 参数见配置参考；这些命令不会替调用方执行网页动作，cleanup 也不代表业务通过。
