# Node 日常状态与许可管理

首次使用先完整执行[部署与运行](../deployment/部署与运行.md)。下列操作都在 Node 设备的部署目录，假定身份在 `.runbridge/node.json`。

查询自己的节点：

```bash
rb_node_id=$(.venv/bin/python -c 'import json; from pathlib import Path; print(json.loads(Path(".runbridge/node.json").read_text())["node_id"])')
.venv/bin/runbridge-node inspect "$rb_node_id" --access-file .runbridge/access.json --output json
```

ONLINE 表示连接有效；资源 READY 表示实际浏览器探测成功；FREE 才能接受新会话。BUSY 表示当前会话占用；UNKNOWN 表示未确认清理，不能强制当作 FREE。

为新调用方签发独立一小时许可：

```bash
.venv/bin/runbridge-node grant --config .runbridge/node.json --resource-id chromium --expires-in 3600 --output .runbridge/access-user2.json
```

borrowed 或自定义资源改成 YAML 对应 resource_id。每个调用方使用单独许可，不能直接接管另一许可的会话。将真实 JSON 和资源说明私密交付；期限以 expires_at 为准。续期通过新签发，不改写旧文件里的时间。

撤销：从交付记录或 access.json 读取真实 grant_id，替换下方演示 ID：

```bash
.venv/bin/runbridge-node revoke --config .runbridge/node.json grant_example
```

撤销会停止该许可的会话和画面。动作已造成的网页修改不会撤销。长期身份继续复用，无需重建节点。
